
# Number Guessing Game

A console-based Java game where players guess a randomly
generated number using hints and limited attempts.

## Features
- Three difficulty levels
- Random number generation
- High and low hints
- Limited attempts per round
- Best score tracking
- Replay option

## Technologies
- Java
- Random
- Scanner
- Loops and conditional statements

## Run Locally
```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```

## Concepts Demonstrated
- Control flow and loops
- Random number generation
- User input handling
- Basic game logic
